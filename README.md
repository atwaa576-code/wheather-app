# 🌤️ Weather App

A fast, modern, and responsive weather application built with React and Vite that provides real-time weather information, temperature, wind speed, and humidity levels.

## 🚀 Features

- 🌡️ Real-time Weather: Displays current temperature and weather conditions.
- 💨 Detailed Metrics: Shows wind speed and relative humidity.
- 🌐 Arabic Localization: Friendly error messages and condition text in Arabic.
- ⚡ Fast Performance: Powered by Vite for optimal build and load speeds.

## 🛠️ Tech Stack

- Frontend: React.js
- Build Tool: Vite
- Styling: CSS3
- API: Open-Meteo API
