# Weather App 🌤️

A simple and responsive weather application that allows users to check weather information for different locations.

## 🚀 Live Demo

[View Live Demo](https://wheather-app-zeta-lime.vercel.app/)

## ✨ Features

- Search for a city and get its weather information.
- Fetch weather data from an external Weather API.
- Display weather information in a clean and user-friendly interface.
- Responsive design for different screen sizes.

## 🛠️ Built With

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Weather API

## 📦 Installation

To run this project locally, follow these steps:

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd weather-app
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser and visit the local URL shown in the terminal.

## 🔑 API Configuration

This project uses an external Weather API to fetch weather data.

If an API key is required, create a `.env` file in the root directory:

```env
VITE_WEATHER_API_KEY=your_api_key
```

Make sure to use the environment variable name required by your code.
